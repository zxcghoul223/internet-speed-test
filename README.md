# Download speed test

Консольный скрипт на Python: выполняет 10 последовательных GET-запросов к заданному URL, полностью читает каждый ответ и выводит среднее время запроса, общий объём и скорость скачивания.

## Запуск

Нужен Python 3.10 или новее. Сторонних зависимостей нет.

Скачайте репозиторий и откройте терминал в его папке. Запустите:

```sh
python speedtest.py "https://www.python.org/static/img/python-logo.png"
```

В Windows вместо `python` можно использовать `py`, в Linux/macOS — `python3`.
Замените URL на прямую ссылку на большой файл: на маленьких ответах задержка соединения сильнее влияет на результат. Скрипт скачивает ресурс десять раз, поэтому расход трафика примерно равен десяти размерам файла.

Пример формата вывода (числа иллюстративные):

```text
Requests: 10
Average request time: 0.250000 s
Total downloaded: 10000000 bytes
Download speed: 32.000000 Mbit/s
```

Справка:

```sh
python speedtest.py --help
```

## Как считается результат

- Каждый следующий запрос начинается после полного чтения предыдущего ответа. Прогрева, параллельных запросов и повторных попыток нет.
- Время измеряется через `time.perf_counter()` непосредственно перед открытием запроса и после чтения всего тела. Включает установку соединения, ожидание сервера и скачивание; не включает печать результатов.
- Среднее время в секундах: сумма времени всех запросов / 10.
- Общий объём в байтах: сумма фактически прочитанных тел ответов. Заголовки HTTP и накладные расходы TCP/TLS не учитываются. Файлы не сохраняются на диск; ответы читаются блоками по 64 KiB.
- Скорость в **Mbit/s (мегабитах в секунду)**: `total_bytes * 8 / total_seconds / 1_000_000`. Это отношение общего объёма к общему времени, а не среднее арифметическое скоростей отдельных запросов.
- Отправляются `Accept-Encoding: identity` и `Cache-Control: no-cache`. Подсчитываются полученные байты тела; сервер может не выполнить пожелания заголовков.
- Стандартный клиент автоматически обрабатывает HTTP-редиректы; они могут добавить сетевые обращения и входят во время соответствующего скачивания. Чтобы получить ровно 10 сетевых GET, используйте конечный URL без редиректов.
- Используется стандартная проверка TLS-сертификатов. Тайм-аут блокирующей сетевой операции — 30 секунд; это не ограничение общей длительности загрузки. Прокси из окружения учитываются стандартным HTTP-клиентом.

Измеряется скорость загрузки с выбранного сервера, включая задержки запросов. Она зависит от файла, сервера и маршрута и не равна гарантированной пропускной способности интернет-тарифа.

При HTTP-ошибке, обрыве ответа с известной длиной, сетевой ошибке или тайм-ауте серия прекращается с сообщением в stderr и кодом 1. Неполная серия не выдаётся за успешный замер. Некорректный аргумент даёт код 2, Ctrl+C — 130.

## Проверки

```sh
python -m unittest -v
```

Тесты используют локальный HTTP-сервер и не расходуют внешний интернет-трафик.
